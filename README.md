# Sonic 1 Definitive

Одностраничный статический сайт для публикации BPS-патча фанатского ROM-хак-проекта **Sonic 1 Definitive**. Разметка, стили и логика разделены по файлам; сборщик, серверная часть, внешние JavaScript-библиотеки и сторонние шрифты не нужны.

## Возможности сайта

- Русская и английская версии с сохранением выбранного языка.
- Переключение тёмной и светлой тем, удобная мобильная навигация и адаптивная вёрстка.
- Прямая загрузка `files/s1patch.bps`, SHA-256 и CRC32 для сверки файлов.
- Проверка опубликованного BPS-патча в браузере.
- Локальное применение патча: выберите исходный ROM или перетащите его на страницу. Браузер проверит размер и CRC32 источника, соберёт результат, проверит его CRC32 и предложит скачать готовый файл.
- Исходный ROM обрабатывается локально и не отправляется на сервер. Сайт не содержит ROM-образ.
- FAQ, доступные элементы управления, поддержка `prefers-reduced-motion` и нативная отправка ссылки.

## Совместимость патча

Страница указывает исходный образ **Sonic the Hedgehog** для Sega Genesis / Mega Drive, ревизия 01. Данные, встроенные в текущий BPS-файл:

| Проверка | Значение |
| --- | --- |
| Формат | BPS1 |
| Размер исходного файла | 524 288 байт (512 KiB) |
| CRC32 исходного файла | `AFE05EEE` |
| Размер результата | 915 280 байт |
| CRC32 результата | `CE9279C3` |
| Размер патча | 187 712 байт |
| CRC32 патча | `0664DDC1` |
| SHA-256 патча | `b024cc1d453b5138e2dd18800107b6d1fb35f5de18e0f1ca0b3cc0b2afe94e72` |

Проверка контрольных сумм подтверждает соответствие файла данным в патче; исходный ROM в репозитории отсутствует. Для применения требуется собственный исходный образ с указанными размером и CRC32.

## Запуск локально

Сайт должен открываться через HTTP/HTTPS, чтобы браузер мог получить BPS-файл для встроенного патчера. Из корня репозитория запустите, например:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Для публикации достаточно разместить файлы репозитория на статическом хостинге; корневая страница GitHub Pages работает без шага сборки.

## Тесты

Тесты используют встроенный тестовый раннер Node.js и не требуют установки пакетов:

```sh
node --test tests/bps.test.mjs
```

Проверяются расчёт CRC32, метаданные и хэш опубликованного патча, действия BPS SourceRead / TargetRead / SourceCopy / TargetCopy (включая перекрывающиеся копирования), а также отказ при неверном исходнике или повреждённом патче.

## Файлы

- `index.html` — доступная HTML-структура и метаданные страницы.
- `styles.css` — адаптивное оформление и цветовые темы.
- `app.mjs` — переключатели интерфейса и браузерный патчер.
- `bps.mjs` — реализация проверки и применения BPS.
- `tests/bps.test.mjs` — автономные тесты формата патча.
- `files/` — BPS-патч и скриншот.
- `assets/favicon.svg` — значок сайта.
