ЧАСТЫЕ ВОПРОСЫGOOD TO KNOW

Перед стартом.Before you start.

Короткие ответы на вопросы о патче и установке.

Quick answers about the patch and how to use it.

Какой ROM нужен?Which ROM do I need?

Нужен исходный Sonic the Hedgehog для Sega Genesis, ревизия 01: файл размером 512 KiB с CRC32 AFE05EEE. Встроенная проверка сообщит, если образ не совпадает.

Use the original Sonic the Hedgehog for Sega Genesis, revision 01: a 512 KiB image with CRC32 AFE05EEE. The built-in checker will tell you if it does not match.

На сайт загружается мой ROM?Is my ROM uploaded to the site?

Нет. Если применяете патч в браузере, файл читается и обрабатывается на вашем устройстве. Для применения браузер скачивает опубликованный BPS-патч; сам ROM-файл остаётся на устройстве.

No. When patching in the browser, the file is read and processed on your device. The browser fetches the published BPS patch for processing; your ROM file stays on your device.

Что такое BPS?What is BPS?

BPS — формат патчей, который описывает изменения относительно исходного файла. Этот сайт также проверяет контрольные суммы исходного и готового файлов.

BPS is a patch format that describes changes from a source file. This page also checks the source and output checksums.

Где взять патчер, если я не хочу использовать браузер?Where can I get a patcher if I do not want to use the browser?

Скачайте s1patch.bps и примените его любой настольной программой, поддерживающей BPS. Укажите исходный ROM как файл-источник и сохраните результат в новый файл.

Download s1patch.bps and apply it with any desktop patching utility that supports BPS. Choose your ROM as the source and save the result as a new file.

Почему проверка отклонила мой файл?Why was my file rejected?

Патч требует точное совпадение размера и CRC32. Проверьте, что это не другая ревизия, не патченный образ и не файл с дополнительным заголовком. Исходный файл при этом не изменяется.

The patch requires an exact size and CRC32 match. Make sure the file is the correct revision, unmodified, and does not contain an extra header. Your source file is never changed.

Это официальный продукт Sega?Is this an official Sega release?

Нет. Это фанатский проект, не связанный с Sega и не одобренный ею. На сайте не размещаются игровые ROM-образы.

No. This is an unofficial fan project and is not affiliated with or endorsed by Sega. No game ROM images are hosted here.
